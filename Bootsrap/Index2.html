🌴 ILLES BALEARS 🌊

Sol, platja, illes i una quantitat preocupant de brainrot.

🏝️ Què són les Illes Balears?

Les Illes Gimnèsies i les Illes Pitiüses són els dos grans grups d'illes que formen l'arxipèlag de les Illes Balears.

🌊 Illes Gimnèsies

Són les illes situades més al nord-est de l'arxipèlag.

🗺️ Illes principals

Les principals Illes Gimnèsies són:

  • 🏝️ Mallorca
  • 🏝️ Menorca
  • 🏝️ Cabrera i el seu subarxipèlag

🪨 Illots principals

  • 🐉 Sa Dragonera
  • 🏝️ Sa Conillera
  • 🌊 Illa de l'Aire

📜 Origen del nom

El nom Gimnèsies prové del grec antic Gymnesiai, relacionat amb gymnos, que significa "nu".

Els grecs i fenicis les varen anomenar així perquè, segons la tradició, els habitants lluitaven amb poca roba i eren famosos com a foners.

🌴 Illes Pitiüses

Les Pitiüses estan situades al sud-oest de l'arxipèlag.

🏖️ Illes principals

  • 🌴 Eivissa
  • 🏝️ Formentera

🪨 Illots destacats

  • 🏝️ Conillera
  • 🌋 Es Vedrà
  • 🌴 Tagomago
  • 🌊 Espardell
  • 🏖️ S'Espalmador

📜 Per què es diuen Pitiüses?

El nom prové del grec antic Pityûssai, relacionat amb els pins que abundaven a les illes.

Per això el nom està relacionat amb les illes cobertes de pins 🌲.
